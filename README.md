# 🚀 ЭТРН Оптимизатор — Автоматизация отчетов и выгрузки из 1С

Комплексное решение для автоматической выгрузки данных из **1С:Предприятие** и формирования сводного отчета по электронным транспортным накладным (ЭТРН).

Разработка ведется на macOS, запуск и работа выполняются на корпоративном компьютере под Windows (с поддержкой обновления без `git.exe` для обхода корпоративных блокировок AppLocker).

---

## 📌 Что делает проект

1. **Автоматически подключается к открытому окну 1С:Предприятие** (обходит блокировки Windows Foreground Lock и особенности раскладки клавиатуры).
2. **Мгновенно переходит в нужные разделы по постоянным навигационным ссылкам (`Shift + F11 / e1cib`)**:
   - **`e1cib/list/Документ.МаршрутныйЛист`** («Маршрутный лист») — устанавливает период (сегодня и 30 дней назад) через плашку периода или `Еще ➔ Установить период...`, формирует список и сохраняет на Рабочий стол в `Модель расчетов.xlsx`.
   - **`e1cib/list/Документ.ЭлектроннаяТранспортнаяНакладная`** («Электронные транспортные накладные») — устанавливает выбранный пользователем период, формирует список и сохраняет на Рабочий стол в `ЭТРН 1с.xlsx`.
   - **`e1cib/data/Справочник.ВариантыОтчетов?ref=946700e0ed9e2e9e11f1495d81d50ffe`** («Контроль подписания перевозчиков по ЭТРН») — открывает сохраненный вариант отчета, заполняет даты в шапке, нажимает `Сформировать` (F5) и сохраняет в `Процент.xlsx`.
3. **Обрабатывает выгруженные данные (`etrn_optimizer.py`)**:
   - Фильтрует завершенные документы.
   - Определяет неподписанные титулы №2, №3, №4 по текущему шагу и состоянию ЭДО.
   - Подтягивает водителя и модель расчетов по связке номера и перевозчика.
   - Строит свод по перевозчикам, водителям и моделям расчетов.
   - Извлекает среднее время подписания из отчета `Процент.xlsx`.
   - Наводит аккуратные корпоративные стили (шрифты Calibri, границы, заливка шапки, автоподбор ширины колонок, автофильтры).
4. **Сохраняет итоговый файл** в папку `Рабочий стол/ЭТРН/ЭТРН_ДД.ММ.ГГГГ.xlsx` с двумя вкладками: `ЭТРН` (детализация) и `Отчет` (свод).

## 📂 Структура проекта

```text
├── config.py           # Конфигурация путей, e1cib ссылок и параметров отчета
├── etrn_optimizer.py   # Модуль аналитики, слияния таблиц и стилизации Excel
├── onec_exporter.py    # Сервис автоматизации 1С (прямые ссылки Shift+F11 / e1cib)
├── run.py              # Главный оркестратор полного цикла с единым вводом дат
├── update.py           # Автообновление проекта с GitHub (без git.exe)
├── requirements.txt    # Зависимости Python
└── .gitignore          # Исключение временных и конфиденциальных файлов
```

## 💻 Использование

### 1. На корпоративном компьютере (Windows)

#### Обновление проекта с GitHub (без git):
```powershell
python update.py
```

#### Запуск полного цикла:
```powershell
python run.py
```
Вам будет предложено ввести дату или диапазон дат:
- `04.11.2026` — выгрузка за этот конкретный день
- `03.11.2026-05.11.2026` — выгрузка за диапазон дат
- Нажатие `Enter` — выгрузка за вчерашний день

Скрипт сам переключится на 1С, по прямым ссылкам выгрузит 3 таблицы и соберет итоговый отчет.

#### Дополнительные ключи запуска:
```powershell
# Автоматический режим со вчерашней датой (для планировщика задач Windows)
python run.py --auto

# Только обработка уже готовых файлов на рабочем столе (без обращения к 1С)
python run.py --skip-1c

# Запуск на конкретную дату или диапазон через аргумент
python run.py --date 03.11.2026-05.11.2026
```

---

### 2. На компьютере разработчика (macOS)

На macOS скрипт автоматически работает в **Mock-режиме (симулятор)**:
- Выводит пошаговый лог действий в 1С.
- Позволяет тестировать логику без наличия Windows и 1С.
